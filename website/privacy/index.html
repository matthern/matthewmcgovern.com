Privacy Policy

Last updated: 25 September 2026

This website

matthewmcgovern.com is a personal site. It does not ask visitors for personal information, it has no accounts or sign-in, and it sets no tracking or advertising cookies. The site is served through Cloudflare, which processes requests and may keep standard server logs, such as IP addresses, on its own terms.

Personal applications

I run private applications for my own use only. They are not offered to the public and have no other users. One of these is "rclone-offsite", which copies backups from my home server to my own Google Drive.

Google user data

rclone-offsite signs in to my own Google account using Google OAuth, with the drive.file scope. That scope limits it to files it creates itself, so it cannot read anything else in the Drive account.

  • It uploads encrypted backup files from my server to my own Google Drive, and lists and deletes the files it created there as old backups are replaced.
  • The files are encrypted before they leave my network. Their contents are not readable by anyone who does not hold my encryption keys.
  • No data belonging to any other person is collected, processed, transferred or sold. There are no other users.
  • Google user data is not used for advertising, and it is not shared with anyone. It is not used to train any AI or machine-learning model.
  • Access tokens are stored on my own systems and can be revoked at any time from the Google account's security settings.
